# Reglas de trabajo: Taller Web

Proyecto de práctica: página web estática (HTML, CSS y JavaScript simples) para un taller de enderezado y pintura llamado "Taller Web".

## Reglas

1. **Alcance:** trabajar solo dentro de la carpeta `taller_web`. No tocar nada fuera de ella.
2. **Diseño:** usar el plugin frontend-design, pero la dirección de diseño del usuario manda sobre cualquier preferencia estética:
   - Estilo sobrio.
   - Sin colores neón.
   - Sin degradados.
   - Sin filas de tres tarjetas idénticas.
3. **Forma de trabajar:** escribir los archivos directamente y resumir al usuario en 5 líneas lo que cambió, sin pegar el código completo en el chat.
4. **Permisos:** pedir aprobación al usuario antes de crear o borrar archivos.
5. **Idioma y tono:** explicar todo en español simple, sin jerga, paso a paso. El usuario es ingeniero industrial y no programa.
6. **Datos de ejemplo:** usar datos de ejemplo marcados como [EJEMPLO] y nunca presentarlos como reales.
7. **Control de versiones:** guardar un punto de restauración con Git después de cada etapa que el usuario apruebe.
8. **Inicio de sesión:** al iniciar una sesión, lee BRIEF.md y PROGRESO.md y resume dónde quedamos antes de actuar.
